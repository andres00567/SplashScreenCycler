# Splash Screen Cycler

Utility plugin that cycles a project's editor and runtime splash images from a folder of PNG files.

## Features

- Runtime splash-image cycling
- Project-configurable splash settings
- Content-enabled plugin
- Early module loading through `PreDefault`
- Bundled `Content/SplashImages` directory for authored splash images

## Module

- `SplashScreenCycler` — Runtime

## Basic setup

1. Copy the plugin into your project's `Plugins` directory.
2. Enable **Splash Screen Cycler**.
3. Add the PNG files you want to cycle to the configured splash-image folder.
4. Configure the plugin through its splash-screen settings.

Additional notes for the bundled image folder are available in [Content/SplashImages/README.md](Content/SplashImages/README.md).
